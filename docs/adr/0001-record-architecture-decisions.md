# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-11-20

## Context

Setu is an open-source project that expects outside contributors and, later, enterprise reviewers. Both need to see why the project is built the way it is.

## Decision

Significant technical decisions are recorded as short Markdown files in `docs/adr/`, numbered in order and based on `0000-template.md`. An ADR is proposed in a pull request and accepted when merged. Accepted ADRs are not edited; a new ADR supersedes an old one.

## Consequences

Decisions are discoverable and reviewable. Writing an ADR adds a small cost to big changes, which is intended.
